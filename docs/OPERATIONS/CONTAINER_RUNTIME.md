## 1. Base Images (Verified by Repository Evidence)

| Container | Image | Digest Pin (CI) | Validation |
|-----------|-------|-----------------|------------|
| API Builder | `node:22-alpine` | `@sha256:...` | `pnpm build` 11/11 passes; `@muf/tbit-core` compiles on musl |
| API Runner | `node:22-alpine` | `@sha256:...` | Same base; runtime `dist/main.js` starts successfully |
| Web Builder | `node:22-alpine` | `@sha256:...` | Vite/TypeScript build passes |
| Web Runner | `nginx:alpine` | `@sha256:...` | Serves SPA; proxies `/api/` to `api:3001` |

**Why Alpine?** Minimal attack surface, musl libc validated by existing CI builds. No native module failures observed in `@muf/tbit-core` or any workspace package.

**Why Node 22?** LTS (Active LTS until Oct 2025, Maintenance until Oct 2026). Matches `package.json#engines` and CI matrix.

## 2. Non-Root Execution (Verified)

| Container | User | UID | GID | Verification Command |
|-----------|------|-----|-----|---------------------|
| API | `nodejs` | 1001 | 1001 | `docker exec aios-api id -u` → `1001` |
| Web (nginx) | `nginx` | 101 | 101 | `docker exec aios-web id -u` → `101` |

**UID 1001 Rationale**: Avoids collision with host UID 1000 (common default). Existing Dockerfile established this pattern.

**UID 101 Rationale**: `nginx:alpine` default user. No custom user needed; runs non-root by default.

## 4. Healthcheck Strategy

| Service | Probe | Endpoint | Compose Config |
|---------|-------|----------|----------------|
| API | Readiness | `GET /readyz` | `test: ["CMD", "wget", "-q", "--spider", "http://localhost:3001/readyz"]` |
| API | Liveness | `GET /livez` | Documented for K8s (not used in Compose v2) |
| Web | Liveness | `GET /health` | `test: ["CMD", "wget", "-q", "--spider", "http://localhost/health"]` |

**Readiness vs Liveness**: 
- `/livez` = process alive (always 200 if Node running)
- `/readyz` = vault initialized + secrets present (503 until `POST /api/v1/tbit/vault/init`)
- Compose `depends_on: api: condition: service_healthy` gates on **readiness**

## 5. Secret Management

**No Defaults in Compose**: 
- Removed `TBIT_API_KEY=${TBIT_API_KEY:-changeme}`
- Now: `TBIT_API_KEY=${TBIT_API_KEY}` (required, no default)

**Source of Truth**: Repository-root `.env` generated by:
```bash
pnpm run setup:secret  # node scripts/setup-tbit-secret.mjs
```
Generates identical `TBIT_API_KEY` and `VITE_TBIT_API_KEY`.

**Injection**: 
```bash
docker compose --env-file .env up -d
```

**Never in Image**: Secrets never baked into Docker images. Verified by:
```bash
docker history aios-api --no-trunc | grep -i secret  # → no matches
```

## 6. Security Headers

### API (helmet via `securityHeadersMiddleware`)
- `Content-Security-Policy` (restrictive)
- `X-Content-Type-Options: nosniff`
- `X-Frame-Options: SAMEORIGIN`
- `Strict-Transport-Security` (HSTS)
- `Referrer-Policy: strict-origin-when-cross-origin`
- `Permissions-Policy` (restrictive)

### Web (nginx)
```nginx
add_header X-Frame-Options "SAMEORIGIN" always;
add_header X-Content-Type-Options "nosniff" always;
add_header Referrer-Policy "strict-origin-when-cross-origin" always;
add_header Content-Security-Policy "default-src 'self'; script-src 'self' 'unsafe-inline' 'unsafe-eval'; style-src 'self' 'unsafe-inline'; img-src 'self' data: https:; font-src 'self' data:; connect-src 'self' http://api:3001; frame-ancestors 'self'; base-uri 'self'; form-action 'self';" always;
```

**CSP `unsafe-eval` Justification**: Three.js/WebGL requires runtime shader compilation via `eval()` / `new Function()`. Mitigated by:
- `connect-src` restricted to `http://api:3001` only
- All other directives `'self'`
- No external script sources

## 7. T-Bit Vault Persistence

| Path | Container | Host | Owner | Purpose |
|------|-----------|------|-------|---------|
| `/data` | api | `tbit-data` volume | `nodejs:nodejs` (1001) | Vault root |
| `/data/spaces` | api | `tbit-data` volume | `nodejs:nodejs` (1001) | T-Bit spaces (created at runtime) |

**Dockerfile**: `RUN mkdir -p /data && chown -R nodejs:nodejs /data`

**Compose**: `volumes: - tbit-data:/data`

**Environment**: `TBIT_VAULT_ROOT=/data/spaces`

**Verification**:
```bash
docker exec aios-api ls -la /data/spaces
# After vault init: shows vault directories

## 9. Build & Run Commands

### Build
```bash
docker compose build
```

### Run (requires root `.env` from `pnpm run setup:secret`)
```bash
docker compose --env-file .env up -d
```

### Validate
```bash
# Compose config valid
docker compose config

# Both services healthy
docker compose ps
# NAME       STATUS              PORTS
# aios-api   Up (healthy)        0.0.0.0:3001->3001/tcp
# aios-web   Up (healthy)        0.0.0.0:3000->80/tcp

# Endpoints
curl -f http://localhost:3001/health    # 200
curl -f http://localhost:3001/livez     # 200
curl -f http://localhost:3001/readyz    # 200 (after vault init) or 503
curl -f http://localhost:3001/metrics   # 200 (Prometheus text format)
curl -f http://localhost/health         # 200 (nginx)
curl -f http://localhost/api/v1/tbit/vault/status  # 200/401 via proxy

# Non-root
docker exec aios-api id -u   # 1001
docker exec aios-web id -u   # 101

# Security headers
curl -I http://localhost/ | grep -i "x-frame\|x-content\|content-security"

# Volume persistence
docker exec aios-api ls -la /data/spaces

## 10. Shutdown Behavior

| Signal | API (dumb-init) | Web (nginx) |
|--------|-----------------|-------------|
| SIGTERM | Forwarded to Node; graceful shutdown | `nginx -s quit` (graceful) |
| SIGKILL | Container killed | Container killed |

**dumb-init** ensures Node receives signals properly and reaps child processes.

---

## 11. Restart Policy

```yaml
restart: unless-stopped
```
- Containers restart on failure
- Survive host reboot (if Docker daemon starts)
- Do not restart if explicitly `docker compose stop` / `down`

## 12. Troubleshooting

| Symptom | Check |
|---------|-------|
| API healthcheck fails | `docker logs aios-api` — verify `/readyz` logic; vault may not be initialized |
| Web healthcheck fails | `docker logs aios-web` — nginx config error or port conflict |
| CSP errors in browser | DevTools Console — verify Three.js loads; `unsafe-eval` required |
| Vault init fails | `curl -X POST http://localhost:3001/api/v1/tbit/vault/init` — check `TBIT_API_KEY` |
| Permission denied on `/data` | `docker exec aios-api id -u` → 1001; volume ownership |
